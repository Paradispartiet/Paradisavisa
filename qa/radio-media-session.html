Test på iPad

  1. Trykk Spill og kontroller at testlyden høres.
  2. Prøv Pause, Spill, Neste og Forrige.
  3. Start lyden på nytt, lås skjermen og sjekk om den fortsetter, og om avspillingskontrollene vises.
  4. Prøv hodetelefon- eller Bluetooth-knapper og bytt til en annen app.
  5. Åpne denne siden igjen og les hendelsesloggen nedenfor.

Testsporene varer ca. 45 sekunder hver. En lokalt åpnet HTML-fil kan gi andre resultater enn HTTPS. Lyd bak låseskjermen avhenger også av iOS og enheten.
